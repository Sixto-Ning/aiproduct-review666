A · 实物与宣传不符
A1 判断申诉主张

A2 具体场景对照
A2a 尺码数值不符(标M实收L)；A2b 版型/廓形不符(标直筒实收腰)；A2c 尺码标准不一(国标/欧码混标)；A2d 特殊品类尺码体系(鞋/内衣/童装)

① 提供命中订单条码实物图且与页面一致 → APPROVED；② 已改页面且与实物一致 → APPROVED；③ 两者皆无/未改 → REJECTED

B1 页面内部矛盾
标题/参数/详情图间尺码信息矛盾(如标题标M，参数表标L)
B2 图文不合理
如标注「均码」但参数列具具体尺码区间；或参数表自相矛盾
B3 已改页面

B4 不明确/未改页面
→ REJECTED（请核实尺码信息，修改至一致合理后重提）
C · 二次及以上漏发/错发
C1 个例错漏发(非页面问题)
强制要求整改报告(问题原因+解决措施+公章)+ 命中订单条码实物图，二者缺任一 → REJECTED

不强制整改报告，按改页面流程核查PDC即可
D · 信息不全
D1 主张已改页面
查PDC+比对平台尺码表是否完整覆盖所有在售规格维度：完整 → APPROVED；部分缺失 → REJECTED(标注缺哪个尺码维度)
D2 未改/不明确
→ REJECTED（请补充尺码信息后重提）
【信息不全范围说明】尺码信息不全 = 比对平台尺码表(参数/商品属性)是否缺失/部分缺失；只要参数/商品属性有写即视为已具备，不判商详页图片/供应商自制信息。

APPROVED 条件

  1. 个例错发 → 实物图清晰+条码与订单一致+尺码与页面另一款一致
  2. 页面错误 → PDC已改+页面已告知
  3. 信息缺失 → 尺码表已补全且与实物一致
  4. 二次及以上错发 → 核实确为错发+每货号≥2条码实物图+已提供整改报告(问题原因+解决措施+公章)
  5. 漏发 → 核实确为漏发+已补发+证据齐全

REJECTED 条件

  1. 未提供实物图/不清晰(条码/尺码不可识别)
  2. 条码与订单不一致
  3. PDC未修改
  4. 修改不完整(只改参数未改声明/反之)
  5. 改后仍不一致/不合理
  6. 二次及以上错发未满足实物图+整改报告(缺问题原因/解决措施/公章)
  7. 已下架→流人工
